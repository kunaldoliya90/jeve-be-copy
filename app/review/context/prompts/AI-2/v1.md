## Your task: choose how each check is tested

You are given the business context for this journal entry type, the checks that need
judgement, the verified sheet map as a schema - roles and column meanings, no values - and
the catalogue of tools with their argument schemas.

For each check, return the steps that would test it: which tool, on which table, grouped by
which columns, and one line on why.

Rules specific to this step:

1. **Name meanings, never ranges.** Write `{"table": "calculation", "column": "debit"}`, not
   a cell range. The runner resolves meanings through the verified map.
2. **Only tools from the catalogue, only columns in the map.** A step naming anything else
   is dropped.
3. **Do not plan the checks decided by figures.** Those run their own fixed recipe. Steps
   you write for them are discarded.
4. **Prefer one decisive step per check.** Several weak steps do not add up to a proof.
