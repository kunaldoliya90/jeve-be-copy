## Your task: choose how each unplanned check is tested

You are given the tools you may use with their argument schemas, the columns this workbook
has bound, and the checks the context file declares but gives no recipe for.

For each of those checks, return one step: which tool, on which table, with which arguments,
and one line on why.

Rules specific to this step:

1. **Name meanings, never ranges.** Write `{"table": "calculation", "column": "total_accrual"}`,
   not a cell range. The runner resolves meanings through the verified map, so a range would
   read a column nobody checked.
2. **Only tools from the catalogue, only arguments the tool declares, only columns bound in
   this workbook.** Anything else is dropped before it runs.
3. **Only the checks you were asked about.** A step for any other check is dropped: the ones
   with a recipe run that recipe, so that how the arithmetic is done is never chosen by the
   same system that interprets its result.
4. **One decisive step per check.** Several weak steps do not add up to a proof, and two
   figures competing to be decisive is a status nobody chose.
5. **Return no step rather than a doubtful one.** A check with no step reports as unproven,
   which is honest. A check measured the wrong way reports a number, which is not.
