## Your task: say what each sheet in this workbook is

You are given a short description of a workbook's shape - sheet names, row counts, header
labels, column types, exact column totals and a few sample values from short category
columns. You are not given the workbook, and you will not be.

You are also given a catalogue of the journal entry types this system knows. You are **not**
told which one the preparer selected. Work it out from the file.

Return:

- `roles` - one role per sheet. A sheet you cannot place is `ignore`, which is a real answer
  and better than a guess.
- `tables` - for each table the JE type asks for, where it sits and which column letter
  carries which meaning.
- `facts` - the cell holding each named fact. Name the cell only; its value is read by code.
- `evidence` - which sheets or pictures satisfy each expected evidence item.
- `name_cells` - cells holding people's names, so they can be scanned for.
- `je_type`, `je_type_confidence`, `je_type_citations` - the type you believe this is, and
  the cells that prove it.

Three rules specific to this step:

1. **Identify a sheet by the columns it holds, never by its name.** One workbook holds its
   entire calculation on a tab called `DENT`.
2. **At least one citation must sit outside the posting table.** The posting tab's own
   labels are the preparer's claim; the calculation, methodology and master tabs are
   evidence.
3. **`unknown` is a valid `je_type`.** An unrecognised workbook routes to a person. A
   confidently wrong one does not.
